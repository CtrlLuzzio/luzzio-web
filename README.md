## AI Usage Disclosure

This website was built with the assistance of AI (Gemini to be precise), acting as a pair-programmer and technical consultant.

While AI was a valuable tool to speed up the workflow, I maintained full control over the project. All core architectural decisions, design choices, tech stack selection, and final code implementations were strictly directed, reviewed, and authorized by me.

In the spirit of transparency, here is a detailed breakdown of how AI was integrated into the workflow:

* **UI/UX & Architectural Discussions:** Bouncing off layout concepts, design choices and maintaining consistent component layering across the site.
* **Backend Architecture:** Assisting in the setup of server-side `Astro Actions` and `Zod` schemas to securely handle the Twitch API and form validations without exposing credentials.
* **Debugging & Code Quality:** Troubleshooting CSS cascade conflicts with Tailwind v4 and ensuring deprecated code was properly refactored.
* **Copywriting:** Refining the text and catching "false friends" or translation nuances.

**TL;DR:** I drove the car, the AI just read the map.
