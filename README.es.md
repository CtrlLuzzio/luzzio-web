# luzzio-web

Este repositorio contiene el código fuente para (link del sito web en progreso), un sitio web estático basado en Astro que funciona como blog personal y portafolio profesional abarcando mis multiples disciplinas: Desarrollador de Software, Jugador Competitivo de Juegos de Pelea y Creador de Contenido.

## Stack Técnico

* **[Astro](https://astro.build/)**
* **[Tailwind CSS](https://tailwindcss.com/)**

## Declaración de Uso de IA

Este sitio web fue construido con la asistencia de IA (Gemini, para ser exactos), actuando como *pair-programmer* y consultor técnico.

Aunque la IA fue una herramienta valiosa para acelerar el flujo de trabajo, mantuve el control total sobre el proyecto. Todas las decisiones arquitectónicas clave, elecciones de diseño, selección del stack tecnológico y las implementaciones de código finales fueron dirigidas, revisadas y autorizadas estrictamente por mí.

En aras de la transparencia, aquí hay un desglose detallado de cómo se integró la IA en el flujo de trabajo:

* **Discusiones sobre Arquitectura y UI/UX:** Validación e intercambio de conceptos de diseño y maquetación, manteniendo la consistencia visual y jerarquía de contenedores en todo el sitio.
* **Arquitectura Backend:** Asistencia en la configuración de `Astro Actions` del lado del servidor y esquemas de `Zod` para manejar de forma segura la API de Twitch y las validaciones de formularios sin exponer credenciales.
* **Debugging y Calidad de Código:** Resolución de conflictos de cascada CSS con Tailwind v4 y refactorización de código obsoleto (*deprecated*).
* **Copywriting:** Refinamiento de los textos en ambos idiomas, corrigiendo "falsas cognadas" y matices de traducción.

**TL;DR:** Yo conduje el auto, la IA solo leyó el mapa.
